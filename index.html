Import multiple videos at once

Select a .json file containing your video collection. All valid videos will be added to your existing library in one go.

Supported format: a JSON array of videos, or an object containing a "videos" array.
[
  {
    "title": "My Video",
    "tags": ["gaming", "tutorial"],
    "thumbnail": "https://example.com/thumb.jpg",
    "videoLink": "https://example.com/video.mp4"
  }
]

Required: title and videoLink. Tags and thumbnail are optional. Also accepts "url" or "videoUrl" as the video link field.
